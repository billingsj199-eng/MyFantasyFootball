# simlab-backup

Orphan backup branch for `E:\MyFantasyFootball\sim_lab` (the private projection + Monte Carlo engine, which lives OUTSIDE the site repo; see sim_lab/README.md). Sibling of `extensions-backup` / `functions-backup`.

Included: all source (.py/.js/.html/.md/.ps1/.bat/.cmd), overrides.js, data/snapshots (weekly lock history), data/sim_tuning.js (weekly tuner state), data/*.json|log|csv (kickoffs, consensus archives, ESPN ROS grid, backtest outputs, live-track logs), scorecards/.
Excluded: __pycache__, *.pkl/*.parquet sample caches, *.bak* engine backups, field_cache/field_out/salary_cache, and data/*.js mirrors (regenerated by refresh_data.py).

Refresh: `git worktree add --detach <tmp> simlab-backup`, copy sim_lab in with the same rules, `git add sim_lab .gitignore README.md`, commit, push.
