# MFF Underdog Draft Helper — Handoff Notes

**Current version:** v0.7.0 (manifest)
**Folder:** `E:\MyFantasyFootball\MyFantasyFootball Files\underdog-extension`
**Loaded as:** Chrome unpacked extension at `chrome://extensions`

## What it does

A Chrome extension that overlays a sidebar on Underdog Fantasy draft pages and surfaces draft recommendations powered by Jack's rankings (from myfantasyfootball.org's `data/d.js`). Click any rec → expanded profile with proj PPG, ADP, last-yr PPG, age, portfolio %, stack info, and roster co-occurrence.

## How the data pipeline works

1. **`export_extension_data.py`** (in parent dir) reads:
   - `data/d.js` — Jack's rankings (ordered by index = rank), team, age, fpR, slR, p25 (last yr PPG)
   - `Site Rankings/UnderdogADP.csv` — udN (Underdog's display name), udA (raw UD ADP)
   - `data/mike_clay_projections.js` — pPg (½ PPR points/game)
2. Outputs `underdog-extension/data/players.json` — 411 players, slim record per player.
3. Run after every rankings/data refresh: `python3 export_extension_data.py`

## How the extension works

**On Underdog page load:**
1. `engine.js` defines `window.MFFEngine` (recommendation logic)
2. `sidebar.js` fetches players.json, injects floating panel
3. `live-watcher.js` polls the pick history ribbon every 1.5s
4. `injected.js` does nothing (kept as placeholder)

**User flow:**
1. Sidebar appears top-right → pick draft slot (1–12) → click "Start Tracking"
2. As picks happen on Underdog, ribbon scanner detects them and posts pick events
3. Sidebar's `state.drafted` and `state.myRoster` update
4. Recommendations refresh on every pick (top 30, scrollable)
5. Click any rec → inline profile expands with full info

**Mid-draft sync:**
- "Sync From Page" button calls `window.__mffBootstrap()` which scans the ribbon
- Replays all completed picks in order through the same matching logic

**Portfolio data flow:**
- Direct upload: "Upload Portfolio CSV" button → parses into {teams, counts, pairs, percent}
- Auto-sync: visit myfantasyfootball.org → `mff-bridge.js` reads `window._udPortfolio` → saves to chrome.storage.local → sidebar reads it on Underdog
- Used for: Portfolio % column on rec cards + Roster co-occurrence section in profile

## Key engine logic (v0.7)

`engine.js` recommend():
- **Pure rank-based scoring** — no positional need multipliers
- Sorted ascending by rank from selected source (Jack's / UD ADP / FP / Consensus)
- Returns top 30 with stack/need/ADP-tag flags for visual treatment

Sidebar visual flags (no scoring impact):
- **Stack** (green border): rec player creates QB↔WR/TE pairing with someone on roster
- **Need** (cyan left border + "NEED" badge): position-of-need
  - Round 6+: RB if <2, WR if <3
  - Round 8+: QB if 0, TE if 0

## Known issues / quirks

1. **Slot must be set correctly.** The sync attribution logic uses `isMyTurn(pickNum, slot)` to decide whether each pick is "mine" or "other." Wrong slot = wrong roster every time.
2. **Live-watcher used to be DOM-disappearance based** (broken — caught list re-renders as picks). Now uses pick ribbon; far more reliable.
3. **WebSocket interceptor was disabled** in v0.2 because wrapping `window.WebSocket` broke Underdog's runtime ("Illegal invocation"). Live mode is pure DOM observation.
4. **chrome.storage.onChanged** listener auto-updates sidebar when portfolio syncs from MFF site.
5. **File truncation issues during Edit tool calls** — every long edit needs verification + sometimes manual re-append of clipped content.

## Recent decisions

- **Data source:** Jack's rank = position-in-D-array (the site doesn't store a static `myRank` field)
- **Scoring philosophy:** rank dominates; need/round priors are visual hints only (v0.7)
- **Ribbon parsing format:** Underdog renders `USERNAME\n\nX.Y|Z\n\nName Abbrev\n\nPOS - TEAM` (double newlines, no spaces around pipe)
- **Player list does NOT show drafted players** — they're filtered out. So bootstrap relies on the ribbon, not the player list.
- **Naming match:** combines exact + suffix-tolerant + first-initial+lastname+team-abbrev fallback. Aliases for Cameron/Cam Ward, Chigoziem/Chig, Hollywood/Marquise Brown, etc.

## Pending features (not yet built)

## Common gotchas to remember

- After editing extension files: `chrome://extensions` → click refresh icon on the MFF card → confirm new version. Then hard reload the Underdog page (Ctrl+Shift+R).
- Errors page at `chrome://extensions` is sticky — clear all to see fresh errors.
- `window.__mffSidebar` is exposed for console access to state. `window.__mffBootstrap()` runs the ribbon parser. `window.__mffPlayers()` returns the player pool.
- Underdog domain matches: `app.underdogfantasy.com` works because manifest has `*.underdogfantasy.com`.
